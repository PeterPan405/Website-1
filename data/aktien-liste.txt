# Die breite Aktienauswahl – Quelle für scripts/aktien-erzeugen.ts
#
# Spalten, getrennt durch senkrechten Strich:
#   symbol | ticker | Name | Länderkennung | Währung | Branche | Geschäftsmodell
#
# - symbol         Kleinbuchstaben und Bindestriche, wird zur URL
# - ticker         wie bei Yahoo Finance, mit Börsenkürzel (.DE, .PA, .L, .T, .HK …)
# - Länderkennung  ISO 3166-1 numerisch, dieselbe wie auf dem Globus
# - Währung        die Einheit, in der die **Kursquelle** notiert, nicht die des
#                  Landes. Die Londoner Börse stellt Aktien in Pence, und Yahoo
#                  liefert sie so: BP steht dort mit 525,70, gemeint sind 5,26
#                  Pfund. Deshalb `GBp` mit kleinem p und nicht `GBP` – hier
#                  stand lange das Falsche, und die Website zeigte für 26
#                  britische Werte den hundertfachen Kurs mit korrekt
#                  aussehendem Währungskürzel daneben.
# - Geschäftsmodell  ein Satz, ohne Punkt am Ende
#
# Nach dem Ändern: `npm run aktien`, danach `npm run build`.
# Ticker prüft das Skript nicht – ein falscher fällt erst beim Kursabruf auf,
# und zwar als fehlender Kurs mit Warnung, nicht als falscher Kurs.
